# Evergreen Academy: school management app

React (Vite) frontend + Express backend. Dark green and black theme.

    cd backend  && npm install && npm start     # API on :5000
    cd frontend && npm install && npm run dev   # app on :5173

Data is held in memory, so it resets when the API restarts. Swap the `db` object in `backend/server.js` for a real database when you're ready.
